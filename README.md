# Merlin Live Agency

Modern dark and emerald-green landing page for Merlin Live Agency.

## Features
- Premium dark/green visual theme
- Responsive mobile design
- Video showcase
- Smooth scroll and reveal animations
- Glassmorphism-style cards
- Floating Apply Now CTA
- Simple GitHub Pages deployment

## Folder structure
```text
merlin-live-agency/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── VID_20260508_064839_705.mp4
```

## GitHub Pages
Upload all files while keeping the `assets` folder. Then enable GitHub Pages from the repository's Settings → Pages and select the main branch/root folder.
